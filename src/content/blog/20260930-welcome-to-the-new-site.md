## 一句话说清

旧站用了六七年的手写 HTML + MDUI 0.4.3，现在换成 **Astro 7 + mdui 2**（Material Design 3 组件库），构建产物直接推 GitHub Pages，**push 即上线**。

搬家不是为了追新，而是为了把多年的坑一次性填掉。

---

## 这次到底动了什么

### 技术栈

| | 旧站 | 新站 |
| --- | --- | --- |
| 框架 | 无（纯手写 HTML） | **Astro 7**（Content Collections + 集成） |
| 界面 | MDUI 0.4.3 本地打包 | **mdui 2.1.5**（MD3 / Web Components） |
| 部署 | GitHub 网页界面上传 | **GitHub Actions**，push `main` 自动构建发布 |
| 站点地图 | 手写的 `sitemap.xml`，2020 年后再没更新过 | `@astrojs/sitemap` 自动生成 |
| 订阅 | 无 | RSS（`/rss.xml`） |
| 域名 | 早期自定义域名（已停用） | GitHub 默认地址 `915p.github.io` |

### 结构

```
src/
├─ pages/          路由：首页、博客、工具中心、404、RSS
├─ content/blog/   文章（Markdown，带 zod schema 校验）
├─ components/     Nav / Footer / ToolCard
├─ layouts/        Base（SEO、meta）/ Page
├─ data/           工具元数据、字体测试符号数据
└─ styles/         MD3 色调板覆盖 + 设计令牌 + 版式
```

换 UI 库意味着「改一处颜色全站生效」只需要改 `global.css` 里的 MD3 色调板变量（`--mdui-color-*-light` / `-dark`），所有组件与自定义样式同步跟随，且自带暗色模式。

## 顺手清掉的坑

搬家过程里做了一次完整的资产审计，删掉的东西大致分三类：

**外部存档与下载代理** —— 若干早期整页抓取的第三方页面快照、本地打包的字体文件（来源不可追溯）、已经停服的分享 SDK。

**授权无法确认的组件** —— 有一个开源项目的副本早于上游唯一的授权提交，按最严格解释连再分发权都不成立；另一个连作者都找不到。都没有转圜余地，只能移除。

**失效的构建** —— 根目录的 Service Worker 与 manifest 停留在 2020 年的缓存策略，现在只会妨碍新内容更新；两处指向已删除目录的样式引用导致页面裸奔。

> 详细清单见仓库里的 `THIRD_PARTY_NOTICES.md`。顺带修了一处此前的失误：根 `License` 原本用单个 MIT 覆盖整个仓库，这会让人误以为所有第三方组件都是 MIT —— 现在它只声明原创代码的范围，其余指向 notices 文件。
