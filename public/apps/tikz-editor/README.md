# TikZ 图形编辑器

**LaTeX TikZ 图形的所见即所得编辑器**（本站汉化移植版）

可以从零开始画，也可以编辑已有的 TikZ 图形，甚至直接打开论文的 `.tex` 文件改里面的插图。
在画布上拖动元素时，TikZ 源码会**即时同步更新**，并且不会破坏原有的换行与空格等排版。

它最大的价值在于：微调元素位置时**不需要重新编译 LaTeX**，改完即见。

## 它是怎么工作的

与「调用服务端 LaTeX 渲染」的方案不同，这个编辑器**自带一套 TeX/TikZ 实现**，
全部在浏览器本地完成，不联网、不上传：

```
TikZ 源码
   │
   ├─ 解析器（parser）      → 无损 AST + 诊断信息
   ├─ 语义求值（semantic）  → 解析样式、变换、坐标，得到场景图
   ├─ SVG 后端（svg）       → 由场景图生成纯 SVG
   └─ 渲染 API（render）    → 源码到 SVG 的端到端编排
```

因为是自己的渲染器，画布上的每个图元都能反查到它在源码里的位置，
所以拖拽、缩放这些直接操作才能**精确地写回源码**，而不是重新生成一份代码。
文本按 TeX 的排版规则渲染（内置 Computer Modern 字体度量），
所以画布上看到的字距、基线与真实 LaTeX 一致。

## 主要功能

- **可视化画布**：形状、路径、曲线、自由绘制、贝塞尔、矩形、圆形等绘图工具
- **源码编辑器**：TikZ 语法高亮、自动补全、数字拖拽微调（number scrubbing）
- **双向同步**：改画布或改代码，两边即时反映
- **导出**：SVG / PDF / PNG，或导出为独立 LaTeX 文档
- **导入**：SVG / IPE / PowerPoint（.pptx）
- **多图支持**：一个文档里有多个 `tikzpicture` 也能分别编辑
- **对齐与分布**、吸附（网格 / 参考线 / 对象节点 / 对象间距）、图层顺序调整
- **矩阵与树**：矩阵单元格增删、树的子节点/同级节点操作
- **Beamer 幻灯片**：叠加层（overlay）与分页步序的可视化编辑
- **`\foreach` 循环**：支持语句级、路径级、节点级三种形式

## 支持的 TikZ 范围

- **形状**：25 种以上内置形状 —— 矩形、圆、椭圆、菱形、正多边形、星形、箭头形、标注气泡等
- **路径**：直线、曲线、矩形、圆、弧、网格
- **曲线**：带控制点的贝塞尔曲线
- **树**：`child` 操作、树布局、层级与同级样式
- **矩阵**：`matrix of nodes` 与单元格对齐
- **样式**：颜色、线型、填充图案、着色（shading）、变换

部分特性只是**部分支持**（装饰 decorations、graphs、plots）；
`let` 运算这类高级构造尚未实现。编辑器内置了一份能力清单，
可在「开发者面板 → 功能特性」里查看每一项的支持状态。

## 快速上手

1. 打开「文件 → 打开示例…」挑一个示例，或直接在源码面板写 TikZ
2. 用工具栏的绘图工具在画布上添加、编辑元素
3. 选中元素后在右侧「检查器」改属性，或右键调出对齐、图层、路径等操作
4. 完成后用「文件 → 导出」输出 SVG / PNG / PDF

## 网页版的限制

本站托管的是**网页版**，以下功能属于桌面版或需要外网：

| 功能 | 网页版情况 |
| --- | --- |
| Codex AI 助手 | 不可用，会提示「仅在桌面版可用」 |
| 本机 LaTeX 编译 | 不可用；「显示编译后的图形」改为尝试从 CDN 加载 TikZJax，需要外网可达 |
| 从 arXiv 打开 | 需要能访问 arxiv.org |
| 原生文件读写 | 依赖 File System Access API；Firefox / Safari 下退回浏览器下载 |

绘图、编辑、双向同步、导出这些核心功能**全部在本地完成，不需要联网**。
